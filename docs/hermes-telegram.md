# Hermes Agent + Telegram: обучение с телефона

Это основной сценарий «учусь с телефона»: Hermes работает на вашем сервере/ноутбуке, вы общаетесь с ним в Telegram, а раз в день бот сам напоминает про уроки (без затрат на LLM).

```
 телефон ── Telegram ── Hermes gateway ──┬── скиллы: study-plan, daily-lesson, teach, visualize
                                          ├── команда `learn` (прогресс, повторения)
                                          └── cron: learn-nudge.sh → «📚 Время учиться!» в Telegram
                                                          ↕ (по желанию) git sync
                                          ~/learning  ← планы и прогресс (приватный git-репозиторий)
```

## 1. Подготовка Hermes и Telegram (если ещё не сделано)

По документации Hermes ([Telegram](https://github.com/NousResearch/hermes-agent/blob/main/website/docs/user-guide/messaging/telegram.md)):

1. В Telegram напишите `@BotFather` → `/newbot` → скопируйте токен.
2. Узнайте свой числовой ID (`@userinfobot`).
3. `hermes gateway setup` → Telegram, либо в `~/.hermes/.env`:
   ```
   TELEGRAM_BOT_TOKEN=...
   TELEGRAM_ALLOWED_USERS=<ваш numeric id>   # без этого шлюз отвечает никому
   ```
4. Напишите боту что угодно и выполните в чате `/sethome` — туда будут приходить напоминания (`TELEGRAM_HOME_CHANNEL`).
5. `hermes gateway start` (или `hermes gateway install`, чтобы шлюз жил как сервис — **cron работает только пока запущен шлюз**).

## 2. Установка обучающей системы

```bash
git clone https://github.com/obebe11/learn ~/learn
cd ~/learn
./integrations/hermes/install.sh --language ru --timezone Europe/Moscow
```

Скрипт (можно запускать повторно после `git pull`):

- ставит команду `learn` в `~/.local/bin`;
- создаёт каталог данных `~/learning` (планы, прогресс, `profile.md`);
- копирует скиллы `teach`, `visualize`, `study-plan`, `daily-lesson` в `~/.hermes/skills/`;
- генерирует `~/.hermes/scripts/learn-nudge.sh` для cron.

**Альтернатива копированию** — подключить репозиторий как внешний каталог скиллов в `~/.hermes/config.yaml` (тогда `git pull` обновляет скиллы сам):

```yaml
skills:
  external_dirs:
    - ~/learn/skills
```

> Если терминал Hermes работает не локально, а в контейнере/на удалённом бэкенде, команда `learn` и каталог `~/learning` должны быть видны *там* (смонтируйте или установите внутрь). Иначе агент не сможет читать и писать прогресс.

## 3. Ежедневное напоминание (cron без LLM)

```bash
hermes cron create "0 9 * * 1-6" --no-agent --script learn-nudge.sh --deliver telegram --name learn-nudge
hermes cron list
```

Как это работает: по документации Hermes «no-agent» задача просто запускает скрипт и отправляет его stdout; **пустой вывод = тихий пропуск**. `learn nudge` печатает текст, только если на сегодня есть уроки или повторения и квота ещё не выполнена — в выходной или после выполненных уроков бот молчит.

Пример сообщения:

```
📚 Время учиться!
Сегодня: 2 урока + 4 повторения · серия 5 🔥
• L07 · Циклы for
• L08 · Списки
Напиши /daily-lesson, чтобы начать.
```

Проверьте, что время срабатывает в вашем часовом поясе (cron-выражение вычисляется Hermes; `--timezone` в `install.sh` влияет только на «какой сегодня день» для `learn`).

Нужен другой текст/язык: `learn nudge --language en --cta "/daily-lesson"`; правьте скрипт `~/.hermes/scripts/learn-nudge.sh`.

### Необязательно: еженедельный разбор (LLM-задача)

Раз в неделю агент может прислать итоги. Это уже обычная задача с токенами; промпт должен быть самодостаточным (cron-сессии не видят историю чата):

```bash
hermes cron create "0 18 * * 0" \
  "Run `learn week` and `learn status`, then write a short, encouraging weekly review in Russian: what went well, what slipped, one suggestion for next week. No more than 900 characters." \
  --skill study-plan --deliver telegram --name learn-weekly
```

## 4. Как выглядит жизнь в чате

**Первый раз — создаём план:**

> Вы: Хочу выучить SQL для аналитики, по два урока в день
> Бот (скилл `study-plan`): … задаёт 4–5 вопросов по одному, проводит мини-диагностику (4–8 вопросов с вариантами A–D), ищет программу в интернете, присылает черновик: результаты обучения, модули, дату окончания, как выглядит день. Вы правите → «ок» → он сохраняет план (`learn create`).

**Каждый день:**

> 09:00 бот: «📚 Время учиться! Сегодня: 2 урока + 3 повторения…»
> Вы: `/daily-lesson`
> Бот: разминка (3 вопроса по прошлым урокам, без подсказок) → урок 1 небольшими сообщениями с проверкой после каждой идеи → итоговый мини-тест (A–D) → запись результата → урок 2 → «объясни главное в двух предложениях» → прогресс-бар и анонс завтрашнего дня.

Можно отвечать голосом (Hermes расшифровывает голосовые). Прерваться и вернуться через час или после `/new` — нормально: прогресс хранится не в чате, а в `~/learning`.

**Граф знаний (несколько тем сразу).** Если вы учите параллельно Python, ИИ и английский, план строится как карта из веток с точками соединения — см. [learning-graph.md](learning-graph.md). Бот собирает день из разных веток; «покажи карту» → таблица/текст; картинку (`learn graph --format png`) он отправит тегом `MEDIA:<путь>` (нужен `rsvg-convert`). «Сегодня хочу только ИИ» → `learn today --track AI`.

**Полезные фразы:** «как мой прогресс?», «покажи план», «я отстаю — что делать?», «поставь на паузу на неделю», «хочу 1 урок в день», «добавь тему X в план».

## 5. Rich-сообщения: формулы, таблицы, чек-листы, подсказки

В новых версиях Bot API (10.1+) у ботов есть метод `sendRichMessage`. Одно сообщение содержит ровно один из вариантов: `markdown`, `html` или `blocks`. Что умеет (по спецификации; официальный сайт из моего окружения был недоступен, сверяйтесь с [core.telegram.org/bots/api](https://core.telegram.org/bots/api)):

| Возможность | Для обучения |
|---|---|
| LaTeX: `$x^2$` и блочные `$$…$$` | формулы без Юникод-костылей |
| Таблицы (до 20 колонок) | сравнения, итоги недели |
| Списки с чекбоксами `- [x]` | план дня, прогресс |
| Сворачиваемые блоки `<details>` | подсказки по шагам, разбор решения |
| Спойлеры `\|\|ответ\|\|` | карточки «нажми, чтобы увидеть ответ» |
| Заголовки, цитаты, `==выделение==`, код с подсветкой | структура урока, «главная мысль» |
| Картинки, коллажи, слайдшоу, карты | пошаговые иллюстрации |
| Лимит | 32 768 символов и 500 блоков (в уроках держим сообщения короткими) |

Mermaid не поддерживается — поэтому вместо диаграмм используются вложенные списки, таблицы и формулы (шаблоны в `skills/daily-lesson/references/telegram-rich.md`); для геометрии и графиков остаются картинки.

**Включение (оба шага обязательны, иначе формулы придут сырыми `$…$`):**

1. В Hermes (по PR NousResearch/hermes-agent#44829 флаг по умолчанию выключен; проверьте в документации своей версии):
   ```yaml
   # ~/.hermes/config.yaml
   gateway:
     platforms:
       telegram:
         extra:
           rich_messages: true
   ```
   Hermes отправляет Markdown агента через `sendRichMessage`, а при ошибке откатывается на обычный MarkdownV2. Известные ограничения: настройки превью ссылок на этом пути не действуют; потоковый вывод в группах остаётся на MarkdownV2.
2. Скажите системе, что rich включён: `learn config chat_format rich` (или `install.sh --rich`). Скиллы читают это из `learn today` и начинают использовать LaTeX, таблицы, чек-листы и `<details>`. Вернуть обычный режим: `learn config chat_format plain`.

Напоминания без Hermes тоже умеют rich: `TELEGRAM_RICH=1 integrations/generic/notify.sh` шлёт через `sendRichMessage` (жирный заголовок, чек-лист уроков) и при ответе 4xx переходит на обычное сообщение; при таймауте/5xx **не** повторяет отправку (исход неизвестен, чтобы не плодить дубликаты). Эту ветку я проверял на заглушке API, а не на живом боте — попробуйте один раз вручную.

**Что остаётся верным в обоих режимах:** ответы длиннее 4096 символов Hermes режет на части (поэтому сообщения короткие, один вопрос за раз); квизы — варианты A–D, правильный ответ не показывается до вашего ответа; голосовые сообщения расшифровываются.

## 6. Если что-то не работает

| Симптом | Что проверить |
|---|---|
| Бот молчит | `TELEGRAM_ALLOWED_USERS` задан? `hermes gateway status` |
| `/daily-lesson` не находится | Скиллы скопированы в `~/.hermes/skills`? Перезапустите шлюз/новая сессия `/new` |
| Напоминания не приходят | Шлюз запущен? `hermes cron list`; `learn nudge` вручную — если пусто, то нет заданий на сегодня; `/sethome` выполнен? |
| «command not found: learn» у агента | Агенту нужен PATH с `~/.local/bin`; либо пусть вызывает `python3 ~/learn/scripts/learn.py` |
| Видны сырые `$…$` и `**` | Rich включён в `learn`, но не в Hermes (или Hermes откатился на MarkdownV2): `learn config chat_format plain` |
| Прогресс «пропал» | `LEARN_HOME` у шлюза и у вас в shell разный? Смотрите `learn --home ~/learning status` |
