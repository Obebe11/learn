# Знания: утверждения, цепочки, практика

План говорит, **что и когда** учить: модули, уроки, даты. Слой знаний хранит, **что именно вы выучили**: утверждения из уроков и то, как одно следует из другого. Модель та же, что у [LearnHarness](https://github.com/amosblomqvist/learnharness), поэтому обе системы читают данные друг друга.

## Модель

- **Утверждение** (`P001`) — одно верное и самостоятельное высказывание плюс короткое имя для показа. Пример: «Строки таблицы не упорядочены, поэтому на строку можно сослаться только по значениям» с именем «Первичный ключ». `kind`: `truth` — принимается как есть (безусловная истина из `teach`), `derived` — выводится из других.
- **Цепочка** (`A001`) — посылки, которые **вместе** дают вывод: `P001 ∧ P002 ⟹ P003`. Два разных довода в пользу одного вывода — это две цепочки, а не одна с общим списком посылок.
- **Источники** — уроки, где утверждение проходили (`py/L03`), или сессии LearnHarness, откуда оно импортировано.
- **Карточки** повторения можно связать с утверждениями (`learn card add … --facts P003`): тогда забывание карточки — это сигнал о конкретном утверждении.

Уровень понимания **нигде не хранится**. Его каждый раз выводят из того, что система уже знает: оценка урока, забывания карточек, уверенные ошибки в повторениях, исходы практики. `learn fact list` показывает эти доказательства рядом с каждым утверждением.

Всё лежит в `~/learning/knowledge.json` — один файл на все планы, чтобы связывать идеи из разных предметов. Файл синхронизируется вместе с остальными данными через `learn sync`.

## Как это входит в занятие

1. **Диагностика** при создании плана → `learn probe set`: по каждой ветке — что получается, где обрывается, какие заблуждения видны. `learn today` потом показывает «⚠ watch for» — заблуждения, за которыми нужно следить на уроках.
2. **Урок** → в конце агент записывает, что было пройдено: `learn fact add --lesson L07` и `learn chain add`. В следующий раз `learn today` показывает эти утверждения под уроком (◆), а карточки создаются с `--facts`.
3. **Практика** (`skills/practice`, уроки-повторения) → `learn practice pick` выбирает самые слабые утверждения из пройденных уроков. Порядок: промахи сегодняшнего дня на перепроверку → промахи и подсказки → забытые карточки → низкие оценки → давно не тронутые. Цели чередуются по урокам, а режим идёт по порядку «вспомнить → различить → собрать цепочку». После каждой задачи — `learn practice log` с исходом, ступенью подсказки (R0–R5) и типом промаха. Практика **не** сдвигает расписание карточек.
4. **История** → `learn history` выводит уроки, повторения (качество и уверенность) и практику по дням. По ней удобно объяснять новое через уже знакомое и искать то, что ускользает.

## Перенос старых планов

У уроков, пройденных до появления слоя знаний, есть только `nodes` — «ключевые идеи» из плана. Перенос делается так:

```bash
learn fact seed                  # черновики утверждений из ключевых идей пройденных уроков (--all — из всех)
learn fact list --drafts         # что осталось переписать
learn fact edit P004 --statement "Одно точное утверждение" --name "Короткое имя" --kind truth
learn chain add --premises P004,P005 --conclusion P006 --lesson L03
learn card edit py/C012 --facts P004   # связать старые карточки
```

Сам план менять не нужно: слой знаний добавляется рядом и ничего не ломает. `learn fact seed` безопасно запускать повторно — уже перенесённые идеи он пропускает.

## Обмен с LearnHarness

Обмен идёт в формате 1 графа LearnHarness (`graph/nodes.jsonl`, `chains.jsonl`, `sources.json`, `format.json`).

- **Импорт**: `learn knowledge import --learnharness ~/.config/LearnHarness/data`. Путь на macOS — `~/Library/Application Support/LearnHarness/data`, на Windows — `%APPDATA%\LearnHarness\data`; подойдёт и сама папка `graph/`.
  - Правила склейки те же, что у LearnHarness: первая строка id задаёт имя и формулировку, поздние формулировки становятся синонимами, одинаковые цепочки склеиваются.
  - Данные LearnHarness только читаются. Формат новее 1 отклоняется, а не угадывается.
  - Повторный импорт ничего не дублирует.
  - После импорта привяжите утверждения к урокам плана: `learn fact link --facts P012,P013 --lesson L05`. Можно и сразу при импорте: `--lesson L05`.
- **Экспорт**:
  - `learn knowledge export` — Markdown-конспект по урокам. Его можно открыть в Obsidian или скормить импорту заметок LearnHarness.
  - `--format json` — те же записи в формате LearnHarness.
  - `--format learnharness --out <пустая папка>` — готовый каталог `graph/`. Существующий граф он не перезапишет.
  - Уроки становятся источниками `src_learn_<план>_<урок>`. При обратном импорте они снова превращаются в ссылки на уроки.

Сессии LearnHarness (ответы, уверенность, «мысли вслух») не импортируются: это приложение с собственным интерфейсом. Импортируется только граф знаний.
