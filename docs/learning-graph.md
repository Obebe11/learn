# Граф знаний: учиться «вширь», а не по одной линии

**Идея.** Вместо одной очереди уроков план — карта из *веток* (Python, ИИ, английский…). Ветки идут параллельно, и в любой день можно учить понемногу из разных. В *точках соединения* (⭐ junctions) нужны сразу несколько навыков — например, «собрать чат-бота» требует и файлов в Python, и промптов. Каждый урок двигает общую цель, но день не превращается в «сегодня только Python, завтра только ИИ».

Так выглядит `learn graph` (реальный вывод; три ветки и ветка проектов с точками соединения):

```
🗺 AI career — 4/15
✅ done · ▶ ready · 🔁 retry · 🔒 locked · ⭐ junction

PY · Python  ████░░░░░░ 2/5
  ✅P1 → ✅P2 → ▶P3 → 🔒P4 → 🔒P5
AI · Основы ИИ  ██░░░░░░░░ 1/4
  ✅A1 → ▶A2 → 🔒A3 → 🔒A4
EN · Английский  ███░░░░░░░ 1/3
  ✅E1 → ▶E2 → 🔒E3
PR · Проекты  ░░░░░░░░░░ 0/3
  ⭐🔒J1 → ⭐🔒J2 → ⭐🔒J3

Junctions (several skills at once):
  ⭐🔒 J1 Чат-бот скрипт ← needs P3 (Файлы и JSON) + A2 (Промпты)
  ⭐🔒 J2 RAG по своим файлам ← needs J1 (Чат-бот скрипт) + P4 (Тесты pytest) + A4 (RAG)
  ⭐🔒 J3 Демо на английском ← needs J2 (RAG по своим файлам) + E3 (Standup)

Ready now: P3 Файлы и JSON [PY] · A2 Промпты [AI] · E2 Объяснить баг [EN]
```

Тот же граф картинкой (`learn graph --format png`): цвет круга — статус, обводка — ветка, ромб — точка соединения.

## Как это работает

- **Ветка = юнит плана.** Внутри ветки уроки идут цепочкой (каждый требует предыдущий). Ветки между собой независимы — любую можно начать первой.
- **Точка соединения** — урок `kind: junction` с `requires: ["P3", "A2"]`. Пока не пройдены *все* указанные уроки из *разных* веток, он закрыт 🔒. Это мини-проект/задача на несколько навыков.
- **День собирается из разных веток.** `learn today` берёт «готовые» уроки (▶) по кругу из веток: сначала уроки на пересдачу (🔁), затем точки соединения, затем ветка, которую вы учили давнее всего. После каждого пройденного урока список обновляется — могли открыться новые.
- **Прыгать можно свободно.** «Сегодня хочу только ИИ» → `learn today --track AI`. Любой готовый урок можно взять вне очереди. Закрытый урок не даст записаться, пока не пройдены предпосылки (`--force`, если вы их уже знаете).
- **Повторения и прогресс — общие**: карточки из всех веток смешиваются в разминке, а прогресс-бар считает весь граф.

## Как попросить агента построить граф

В чате с ботом (скилл `study-plan`) скажите, например:

> Хочу параллельно учить Python и основы ИИ, плюс английский для собеседований. Хочу каждый день понемногу разного. В конце — проект, где всё это нужно сразу.

Агент разобьёт цель на 2–5 веток, найдёт точки соединения (первая откроется рано, когда в обеих ветках будет по 3–5 уроков — чтобы быстро получить отдачу; последняя — итоговый проект), покажет **карту** и дату окончания и дождётся вашего «ок».

Добавить тему позже: «хочу ещё учить SQL отдельно» — агент добавит новую ветку (и, если нужно, точки соединения с другими) в тот же план. Прогресс и id уроков сохраняются.

## Карта: как посмотреть

| Команда | Что показывает | Где удобно |
|---|---|---|
| `learn graph` | ветки цепочками (`✅P1 → ▶P3 → 🔒P4`), точки соединения и что нужно для них, «готово сейчас» | любой чат (в блоке кода) |
| `learn graph --format md` | таблица «ветка · прогресс · готово сейчас» + список ⭐ | Telegram rich-сообщения, Obsidian |
| `learn graph --level units` | одна строка на ветку и связи между ветками | обзор |
| `learn graph --format mermaid` | диаграмма Mermaid (то же автоматически лежит в `PLAN.md`) | Obsidian, GitHub |
| `learn graph --format svg` / `png` | картинка: цвет — статус, обводка — ветка, ромб — точка соединения | отправить в Telegram |

Обозначения: ✅ пройдено · ▶ готово к изучению · 🔁 пересдать · 🔒 закрыто (ждёт предпосылок) · ⭐ точка соединения.

**PNG** строится из SVG внешним конвертером: нужен `rsvg-convert` (`apt install librsvg2-bin`), либо Inkscape, либо ImageMagick с поддержкой SVG. Если ничего нет, команда сохранит `.svg` и объяснит, что поставить; текстовая и `md`-карты работают всегда. В Hermes картинку отправляют тегом `MEDIA:/путь/к/graph.png` (путь команда печатает сама).

## Перевести существующий линейный план в граф

Если у вас уже идёт линейный план (например, Python), а хочется добавить параллельную ветку:

1. Откройте `~/learning/plans/<slug>/plan.json`, добавьте `"graph": true` и новые юниты-ветки (или попросите агента).
2. Внимание: в режиме графа **юниты становятся параллельными**. Если часть юнитов должна идти строго после предыдущих, добавьте первому уроку такого юнита `requires: ["<последний урок предыдущего>"]`. `learn create --update` предупредит об этом.
3. `learn create <slug> --file plan.json --update` — пройденное сохраняется (прогресс привязан к id уроков).
4. `learn graph` — проверьте карту.

Формат урока в графе:

```json
{"id": "J1", "title": "Скрипт-чат-бот", "kind": "junction", "requires": ["P3", "A2"],
 "objective": "Собрать скрипт, который читает файл и задаёт вопросы модели",
 "check": "Запускается на новом файле; можете объяснить каждую часть"}
```

## Ограничения

- Один план = один граф. Зависимости между *разными планами* пока не поддерживаются: чтобы ветки могли соединяться, держите их в одном плане.
- Прогноз даты окончания считается по общему темпу (уроков в день × дни), без учёта того, что в конце могут остаться только закрытые уроки одной цепочки.
- «Много разного за день» ограничено `lessons_per_day` (по умолчанию 2). Хотите больше — поставьте 3–4 коротких урока по 15–20 минут.

## Зачем смешивать темы (и где осторожно)

Смена темы заставляет каждый раз заново вспоминать, а не «ехать по накатанной», — это та же логика, что у интервальных повторений и чередования (interleaving). Оговорка: сильнее всего чередование изучено на *похожих* типах задач (в основном математика); смешение совсем разных предметов помогает в основном через разнесение во времени и мотивацию, а переключение имеет цену. Поэтому по умолчанию в день берётся **по одному уроку из ветки**, а не по пять — подробности и источники в [learning-science.md](learning-science.md).
